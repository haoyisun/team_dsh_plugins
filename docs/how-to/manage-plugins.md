# 添加和管理外源插件

本页说明如何在 DSH Web 中管理当前用户的 npm 外源插件。工作区内开发的插件见[新增插件](add-plugin.md)。

## 打开插件管理

完成仓库接入并启动 DSH：

```powershell
pnpm run init
npx @deepseek-ai/dsh web
```

打开设置侧边栏中的“插件管理”。页面读取 Web Profile 的实际安装状态，不使用仓库注册表。

## 设置 npm 镜像源

页面顶部可以为本插件单独设置 npm registry。留空则使用本机或 Profile 的默认源；也可一键填入 `https://registry.npmmirror.com`。接受 `http` 或 `https` 地址，例如华为云、腾讯云等带路径前缀的镜像；保存时会补上末尾 `/`，以免 pnpm 拼错包地址。

该设置保存在 DSH settings 的 `plugin-manager` namespace，只作用于本页的版本查询和安装子进程，不会改写 `~/.npmrc` 或 Web Profile 的 `.npmrc`。

## 添加插件

在顶部输入 npm 包名，例如：

```text
@sugarforever/dsh-mcp-apps
```

展开“指定版本（可选）”后，也可填写精确版本：

```text
1.2.3
```

省略版本时解析 `latest`。管理器会先展示精确目标版本、registry、主页及目标包声明的生命周期脚本。确认后，它通过当前 DSH 版本的官方 plugin 流程安装并注册 Bundle。

只接受 npm registry 包名、`latest` 和精确 semver；不接受其他 tag、版本范围、URL、Git spec、本地路径或工作区 scope。

## 查看与检查更新

“外源插件”区域显示当前版本、Bundle 健康状态和 Profile 停用状态。页面打开和窗口重新获得焦点时会自动刷新本地状态，但不会自动联网查询版本。

点击单个插件的“检查更新”，管理器才会联网查询 `latest`。若已在本页设置镜像源，查询走该源；否则沿用 Web Profile 的 pnpm registry、代理和认证配置。认证信息不会返回浏览器。

DSH 系统 Bundle 和仓库工作区插件默认折叠在“系统管理”区域中。它们用于解释 Web Profile 中不可修改的 Bundle，不能从该页面更改。

## 更改或恢复版本

从插件条目的更多操作菜单选择“更改版本”，输入 `latest` 或精确版本。目标低于当前版本时属于降级，仍需要确认。

版本变更成功后，管理器为该包保留一个上一版本号。点击“恢复”可切换回该版本；每次成功切换都会用刚刚替换掉的版本更新恢复目标。

安装、更新、降级或恢复在执行或状态核对阶段失败时，管理器会按操作前快照自动执行补偿：新增失败则移除残留包，版本变化失败则重新安装先前精确版本。页面会明确区分“已恢复”“无需恢复”“无法安全恢复”和“恢复失败”；恢复失败时同时显示脱敏技术详情及当前检测到的实际状态。删除和修复不能还原为此前的缺失或损坏文件，失败后只核对并展示实际状态。

## 删除插件

从更多操作菜单点击“删除”，在原生确认框中核对包名和版本后确认。管理器会从 Web Profile 卸载该直接依赖，并核对 Bundle 注册已经移除。

删除不会清理插件设置、凭据、缓存或业务数据。传递依赖由 pnpm 决定是否保留。

## 让变更生效

Bundle 的添加、删除、修复和版本变化不能热加载。成功操作会在对应插件行保留“待重启”提示；可逆的添加和版本变化可在重启前撤销，删除和修复则只保留状态提示。其他插件仍可继续管理。

可从提示中复制启动命令。回到运行 DSH Web 的终端按 `Ctrl+C`，等待进程退出后重新运行：

```powershell
npx @deepseek-ai/dsh web
```

## 紧急恢复

如果新插件导致 DSH 无法启动，设置页也无法打开。使用官方 CLI 卸载问题包：

```powershell
npx @deepseek-ai/dsh plugin --profile web remove <package>
```

然后重新启动 DSH Web。该命令不会删除插件产生的设置和业务数据。

## 安全说明

安装或更新外源插件会执行第三方包及其依赖，可能包含 npm 生命周期脚本，权限与当前用户相同。界面提供的包描述、作者或主页不构成安全背书；确认前应核对包名、发布者和精确版本。

插件操作全局串行，最长执行五分钟。页面关闭不会取消已经开始的操作；重新打开页面可查看下载与安装、真实状态核对或自动恢复阶段。成功时不展示 CLI 噪声；失败时给出原因、处理建议和可折叠复制的脱敏技术详情。完整凭据和 registry 认证信息不会返回浏览器。
