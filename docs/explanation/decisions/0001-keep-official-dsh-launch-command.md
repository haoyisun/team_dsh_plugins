# ADR-001：保留官方 DSH 启动命令

## 状态

Accepted

## 日期

2026-08-21

## 背景

团队要求插件仓库自动接入，但不希望每次通过仓库包装器启动 DSH。

## 决策

一次性修改 DSH Profile 接入，此后始终运行 `npx @deepseek-ai/dsh web`。维护脚本不得成为 DSH 启动入口。

## 备选方案

- 仓库启动脚本设置专属 `DSH_HOME`：隔离更强，但改变团队启动习惯。
- 每次启动前同步插件：实现简单，但不满足裸命令约束。

## 结果

接入必须持久存在于 DSH Home；仓库移动后需要重新初始化。DSH 启动行为继续由官方 CLI 所有。
