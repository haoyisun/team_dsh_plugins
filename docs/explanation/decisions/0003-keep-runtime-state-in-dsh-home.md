# ADR-003：运行时状态保留在 DSH Home

## 状态

Accepted

## 日期

2026-08-21

## 背景

插件需要设置、持久数据、缓存和凭据。将这些内容放入源码仓库会耦合机器状态、增加泄密风险，并绕过 DSH 已有服务。

## 决策

- 设置使用 DSH settings namespace。
- 持久数据使用 storage-domain。
- 可删除缓存位于 `$DSH_HOME/cache/<id>/`。
- 密钥使用 credentials 或环境变量。
- 仓库只保存代码、注册表、默认值和文档。

## 备选方案

- 仓库内 `data/` 与 `config/`：物理集中，但污染版本控制并使多工作副本争用状态。
- 每个插件自定义绝对路径：灵活，但没有统一生命周期和迁移规则。

## 结果

`.dsh` 仍包含插件状态，但不包含源码副本。解除接入和禁用默认保留数据，删除数据必须是单独且明确的操作。
