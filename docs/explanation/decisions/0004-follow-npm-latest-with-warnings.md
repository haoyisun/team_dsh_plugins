# ADR-004：跟随 npm latest 并告警未知版本

## 状态

Accepted

## 日期

2026-08-21

## 背景

团队希望直接使用 `npx @deepseek-ai/dsh web` 获取 npm `latest`。DSH 当前仍是 Developer Preview，官方明确可能引入破坏兼容的变化。

## 决策

仓库不锁定 DSH 运行版本。`doctor` 维护已验证版本集合；未知版本告警并继续，不阻止启动。协议级不兼容时，先在注册表禁用插件，再完成适配。

## 备选方案

- 固定 DSH 版本：最稳定，但不符合持续使用 latest 的要求。
- 未知版本阻止运行：保护更强，但与团队升级策略冲突。
- 自动回退：需要包装启动流程，违反 ADR-001。

## 结果

“升级不受影响”不是可兑现保证。插件应尽量在自身边界降级，但 manifest、Loader、服务键或 Client 协议破坏仍可能阻止加载。
